# Feature workbench

This session builds on `feat/effects-library-timeline`. Prioritize complete, tested desktop/web features over adding unfinished controls. The target session budget is approximately three hours.

| Idea | Benefit | Status |
| --- | --- | --- |
| Audio sample rate, channel layout and WAV bit depth | Prepare songs, speech and production audio for the intended destination | Implemented |
| GIF repeat, palette and dithering options | Control animation behavior and file size | Implemented |
| Bulk filename templates | Organize converted collections with predictable names | Implemented |
| Timeline markers with names and navigation | Bookmark important moments and review points | Planned |
| Timeline snapping | Make precise cuts and align timed elements | Planned |
| Loop sequence or selected clip | Review short edits without repeatedly restarting | Planned |
| Frame stepping and precise time navigation | Inspect cut points with keyboard or transport controls | Planned |
| Reusable effect settings | Copy effects between clips and save favorite recipes | Planned |
| Caption find and replace | Correct repeated words across caption sets | Planned |
| Source media information | Inspect codecs, frame rate and audio properties | Planned |
| Contact-sheet export | Share a quick visual overview of a video | Backlog |
| Desktop watch folders | Convert newly added files automatically | Backlog |
| Export completion notifications | Know when long jobs finish while working elsewhere | Backlog |
| Multi-track music and voiceover | Mix additional audio with video | Backlog |
| Scene-change detection | Find likely cut points automatically | Backlog |
| Audio loudness meter | Assess clipping and perceived loudness while editing | Backlog |
